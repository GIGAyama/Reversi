# ⚪️⚫️ リバーシ ⚫️⚪️ (Google Apps Script ウェブアプリ)

このプロジェクトは、Google Apps Script (GAS) で作成されたリバーシゲームのウェブアプリケーションです。
公立小学校の児童が休み時間に楽しく遊ぶことを想定しており、GIGAスクール端末（Chromebook）での利用や、学級児童40名程度の同時使用に耐えうるように設計・リファクタリングされています。

## ✨ 概要と特徴

このアプリは、シンプルで直感的な操作でリバーシを楽しめるようになっています。
特に、現場の先生方がアプリをより理解し、管理・保守しやすくするために、以下の点に配慮してリファクタリングを行いました。

*   **豊富な日本語コメント**: コードの各所に詳細な日本語コメントを付与し、プログラムの意図や機能が分かりやすくなっています。専門知識がない先生でも、コードの構造やロジックを理解しやすくなりました。
*   **コードの整理と構造化**: 機能ごとにコードをセクション分けし、見通しを良くしました。これにより、特定の機能を探したり、変更を加えたりする際の労力が軽減されます。
*   **効率的なDOM操作**: 盤面のセルクリックイベント処理を最適化し、多数の児童が同時にアクセスしてもスムーズに動作するように工夫されています。
*   **自己完結型**: `index.html` ファイル一つでゲームのHTML、CSS、JavaScriptの全てが完結するため、管理が非常にシンプルです。

## 🚀 動作環境

*   **対象端末**: GIGAスクール端末 (Chromebook) を含むWebブラウザが利用可能なデバイス
*   **プラットフォーム**: Google Apps Script (GAS)
*   **推奨同時接続数**: 1学級（約40名）程度の同時利用を想定

## 💻 セットアップ方法 (Google Apps Scriptでのデプロイ)

このアプリはGoogle Apps Scriptとして動作します。以下の手順で簡単にデプロイして利用を開始できます。

1.  **Googleドライブにコピー**:
    *   `Code.gs` と `index.html` の2つのファイルをGoogleドライブにアップロードします。
    *   Googleドライブ上で両ファイルを選択し、右クリック → 「アプリで開く」 → 「Google Apps Script」を選択します。これにより、両ファイルがスクリプトプロジェクトとして開かれます。
    *   または、新しいGASプロジェクトを作成し、そこに `Code.gs` と `index.html` の内容をそれぞれコピー＆ペーストすることもできます。
        *   GASエディタで「ファイル」→「新規作成」→「スクリプト」を選択し、`Code.gs` の内容を貼り付けます。
        *   GASエディタで「ファイル」→「新規作成」→「HTML」を選択し、ファイル名を `index` とし、`index.html` の内容を貼り付けます。

2.  **ウェブアプリとしてデプロイ**:
    *   GASエディタのメニューから「デプロイ」→「新しいデプロイ」を選択します。
    *   デプロイタイプの選択で、歯車アイコンをクリックし、「ウェブアプリ」を選択します。
    *   以下の項目を設定します:
        *   **説明**: 例「リバーシゲーム (小学生向け)」
        *   **ウェブアプリを実行するユーザー**: 「自分」を選択します。
        *   **アクセスできるユーザー**: 「全員」または「組織内の全員」を選択します。**(重要: 小学生がアクセスできるように「全員」または「組織内の全員」を選択してください)**
    *   「デプロイ」ボタンをクリックします。
    *   初回デプロイ時には、Googleアカウントの認証を求められる場合があります。「アクセスを承認」をクリックし、画面の指示に従って承認を進めてください。
    *   デプロイが完了すると、「ウェブアプリのURL」が表示されます。このURLをコピーして控えておいてください。

## 🕹️ 使い方

1.  **アプリへのアクセス**:
    *   デプロイ時に取得した「ウェブアプリのURL」をブラウザで開きます。
    *   Chromebooksのお気に入りや、Google ClassroomなどでURLを共有することで、児童が簡単にアクセスできます。

2.  **ゲームの開始**:
    *   画面中央に表示される「⚪️⚫️ リバーシ ⚫️⚪️」の下に、盤面サイズ入力欄と「開始 / リセット」ボタンがあります。
    *   デフォルトの盤面サイズは8x8ですが、4から12までの偶数（4, 6, 8, 10, 12）に変更できます。
    *   「開始 / リセット」ボタンをクリックするとゲームが開始されます。

3.  **プレイ方法**:
    *   緑色の盤面には、現在石を置けるマスが薄い円でハイライトされます。
    *   自分の手番のプレイヤー（手番表示エリアで確認）が、ハイライトされたマスをクリックして石を置きます。
    *   石を置くと、ルールに従って相手の石がひっくり返り、手番が交代します。
    *   置ける場所がない場合は自動的にパスとなります。メッセージエリアに「〇〇はパスしました。」と表示されます。
    *   両プレイヤーが連続でパスするか、盤面が全て埋まるとゲーム終了です。勝敗がポップアップ表示されます。
    *   ポップアップ内の「もう一度」ボタンで新しいゲームを開始できます。

## 👨‍🏫 開発者向け情報 (教員向け)

このセクションは、コードの内容を少し詳しく見てみたい先生方向けです。

### ファイル構成

*   `Code.gs`:
    *   Google Apps Scriptのサーバーサイドコードです。
    *   `doGet(e)` 関数が、ウェブアプリにアクセスがあった際に `index.html` を返す役割を担っています。
    *   基本的に、このファイルの内容を変更する必要はありません。
*   `index.html`:
    *   ゲームの全ての要素（HTML構造、CSSスタイル、JavaScriptロジック）が含まれています。
    *   **CSS部分**: `<head>` タグ内の `<style>` ブロックに書かれています。色やデザインを変更したい場合は、この部分を編集してください。`--bg-color` や `--board-bg` といった `var(--変数名)` の箇所を変更すると、アプリ全体の見た目が変わります。
    *   **JavaScript部分**: `<body>` タグの最後にある `<script>` ブロックに書かれています。ゲームのルール、石の配置、手番の交代などのロジックが記述されています。
        *   コードは「定数とDOM要素の取得」「ゲームの初期化とリセット」「画面の描画関連」などのセクションに分かれており、各関数や重要な箇所には詳細な日本語コメントが付いています。
        *   `gameState` オブジェクトがゲームの状態を全て管理しており、これを理解するとゲームの仕組みが見えてきます。

### 簡単なカスタマイズ例

*   **テーマカラーの変更**: `index.html` 内の `<style>` ブロックにある `:root` セレクタの中の `var(--変数名): #色コード;` の `#色コード` を変更するだけで、アプリ全体の配色を簡単に変更できます。
*   **初期盤面サイズの変更**: `index.html` の `<body>` 内にある `<input type="number" id="board-size" value="8" ...>` の `value="8"` を変更すると、アプリ起動時のデフォルト盤面サイズを変更できます。

## ⚠️ 注意事項

*   このアプリケーションは完全にクライアントサイド（ブラウザ側）で動作するため、ゲームの進行状況はブラウザを閉じると失われます。
*   Google Apps Scriptの制約上、非常に大規模なアクセスがあった場合、一時的にパフォーマンスが低下する可能性もゼロではありませんが、一般的な学級での利用であれば問題なく動作します。
