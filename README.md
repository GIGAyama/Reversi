# ⚪️⚫️ リバーシ (Reversi Online for School) ⚫️⚪️

GIGAスクール端末（Chromebook）やタブレットで、休み時間などに手軽に遊べるリバーシゲームです。 公立小学校での利用を想定し、**「わかりやすさ」「低負荷」「カスタマイズのしやすさ」**を重視して開発されました。

現在、本プロジェクトは **GitHub Pages** を利用して公開されています。

## 🚀 デモ (今すぐ遊ぶ)

以下のURLから直接ゲームをプレイできます。 **[あなたのGitHub PagesのURLをここに貼り付けてください]** *(例: https://[ユーザー名].github.io/[リポジトリ名]/)*

## ✨ 特徴

*   **GIGAスクール端末対応**: Chromebookなどの低スペック端末でもサクサク動作します。
    
*   **ふりがな（ルビ）対応**: 低学年の児童でも読めるよう、重要な漢字にはルビを振っています。
    
*   **インストール不要**: Webブラウザ（Chrome, Edge, Safari等）があればどこでも動きます。
    
*   **教育者フレンドリー**:
    
    *   コード内に詳細な日本語コメントを記述。プログラミングの教材としても活用可能。
        
    *   HTML/CSS/JSが1ファイルに完結しているため、管理が容易。
        
*   **レスポンシブ設計**: 画面サイズに合わせて自動で盤面の大きさが調整されます。
    

## 🛠 セットアップ方法 (GitHub Pagesでの公開)

自分のリポジトリとして公開し、URLを発行する手順は以下の通りです。

1.  **リポジトリをフォークまたは作成**: このリポジトリをフォークするか、`index.html` と `favicon.png` を自分のリポジトリにアップロードします。
    
2.  **Settingsを開く**: GitHubリポジトリのメニューから **Settings** をクリックします。
    
3.  **Pagesの設定**: 左サイドバーの **Pages** を選択します。
    
4.  **公開設定**: `Build and deployment` > `Branch` で `main` (または `master`) ブランチを選択し、`Save` をクリックします。
    
5.  **完了**: 数分待つと、ページ上部に公開URLが表示されます。
    

## 👨‍💻 カスタマイズ方法

`index.html` を編集することで、簡単に自分好みのゲームに変更できます。

### テーマカラーの変更

18行目付近の `:root` セクションにある色コードを変更してください。

```
:root {
    --bg-color: #f0e7d8;     /* 背景色 */
    --board-bg: #006400;     /* 盤面の色 */
    --btn-color: #4a90e2;    /* ボタンの色 */
}
```

### デフォルト設定の変更

盤面サイズの初期値などを変更したい場合は、HTML内の `input` タグの `value` を書き換えます。

## 📂 ファイル構成

*   `favicon.png`: ブラウザのタブに表示されるアイコン
    
*   `README.md`: このドキュメント
